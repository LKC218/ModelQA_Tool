# 爆炸布局集中化优化 — 实施方案

> 日期：2026-09-13 ｜ 状态：待确认 ｜ 影响端：审核端 + 开发端（共用 shared-viewer）｜ 前置：主轴分层 + 碰撞松弛已上线（14:12 修复版）

## 1. 背景与问题

用户反馈：发电机爆炸拆分后布局**散乱**——零件四散（红色二极管飞至左上远处、爪极掉至下方、风扇在右侧），观感不集中。

散乱三来源：
1. **L2 子件全向径向弹出**：33 个子件沿「子件→总成中心」反向弹向四面八方；
2. **松弛推挤方向随机**：嵌套单元被 MTV 沿最小重叠轴顶出，方向不可控（飞出零件的主要来源）；
3. **尺度参数偏大**：总成间隙 0.12×diag、L2 穿出间隙 0.07×diag、松弛 margin/上限层层叠加，100% 时铺开过宽。

## 2. 方案设计（三招，全部在 buildExplode / relaxExplodeOffsets 内部）

### 2.1 L2 位移限制在垂直主轴平面（形态收敛）
- L2 弹出方向 =「子件中心 → 总成中心」反向后**去掉主轴分量**（`dir.addScaledVector(axisVec, -dir·axisVec).normalize()`）；
- 垂直化后方向长度不足（子件几乎在总成轴线上）时，退化方向 = 垂直主轴的固定方向（现行逻辑）；
- 效果：子件全部「挂」在所属总成侧面，与 L1 沿轴排布正交，消灭沿轴乱窜。推出距离公式不变（tExit + rChild + 间隙）。

### 2.2 间距整体收敛（尺度收敛）

| 参数 | 现值 | 新值 |
|---|---|---|
| L1 主轴间隙 `gap` | 0.12×diag | **0.07×diag** |
| L2 穿出间隙 `gapInner` | 0.07×diag | **0.04×diag** |
| 松弛 margin | 0.015×diag | **0.01×diag** |
| 松弛单步上限 maxStep | 0.25×diag | **0.15×diag** |
| 松弛总位移上限 maxShift | 2×diag | **1.2×diag** |

### 2.3 爆炸后整体重心回正（视觉对称）
- 松弛结束后计算爆炸后整体包围盒中心与原始模型中心之差 `offset`；
- 把 `offset`（换算为本地坐标）从每个 L1 单元的 offsetLocal 中减去（L2 随父自动跟随）；
- 效果：爆炸云以原模型中心对称展开，相机取景不再偏斜。
