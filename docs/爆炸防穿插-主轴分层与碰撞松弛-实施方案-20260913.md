# 爆炸防穿插布局优化（主轴分层 + 碰撞松弛）— 实施方案

> 日期：2026-09-13 ｜ 状态：已确认，进入实施 ｜ 影响端：审核端 + 开发端（共用 shared-viewer）｜ 前置：上午已完成二级拆分 + 相机自适应并上线

## 1. 背景与问题

用户反馈：电机模型爆炸后零部件**互相穿插**，希望每个零件拥有独立空间便于观看。根因：现行爆炸是「径向散射 + 固定间距」，无任何碰撞检测；电机类细长装配体零件中心贴近主轴，径向散开后沿轴向仍然叠在一起，内件弹出方向又与壳体移动方向相近。

## 2. 案例调研结论（复刻来源）

| 来源 | 借鉴点 |
|---|---|
| BRICSYS 专利 WO2020048779A1（CAD 装配爆炸） | bbox 相邻排布：沿分离方向把零件移到「装配体最远点 A − 自身最远点 B + gap」 |
| 湖南师大《基于碰撞检测强化的实时爆炸视图自动生成算法》 | 初始分离后用碰撞响应（AABB 相交推挤）消除穿透 |
| Aalborg VR 论文（Real-Time Exploded View Authoring） | LAT 长轴测试：零件沿装配主轴分离；方向候选收敛到少数轴向 |
| 教程级案例（DevDojo/CSDN/掘金风机） | 均为径向散射或人工配置坐标，不采纳 |

**主流交互结论**：机械装配/教学/审核场景的事实标准 = 主轴分层排布（SolidWorks / Apple 拆解图 / iFixit）；碰撞松弛是 CAD 中「工程师手动拖开零件」的自动替代。

## 3. 方案设计

### 3.1 L1 主轴分层排布（替代径向散射）
- 主轴 = 模型整体 AABB 最长轴（电机=转轴）；
- L1 单元按中心在主轴上的投影**升序排序（保持原相对顺序 = 保持装配语义）**，沿主轴依次堆叠：每件目标占位 = 自身主轴投影长度 + `gap(0.12×对角线)`，整体以原模型中心对称展开；
- 位移只取主轴分量，**垂直分量保留原方位**（底板仍在下方、端盖仍在端部），维持装配语境。

### 3.2 L2 子件推出总成
- 方向仍为「子件中心 → 总成中心」反向；退化方向改为**垂直于主轴**（避免窜入主轴邻居空间）；
- 推出距离 = `max(原距, 总成 bbox 沿该方向的出口距离 tExit + 子件半投影 rChild) + gapInner(0.07×对角线)`——一步穿出总成包围盒，不再嵌在总成行程内。

### 3.3 碰撞松弛（防穿插兜底）
- `relaxExplodeOffsets(diag)`：世界空间建模每个单元总位移（L2 总位移 = 所属总成位移 + 自身相对位移）；
- 3 轮迭代：全部单元 AABB（origBox + 位移）两两相交检测 → 沿**最小重叠轴**（MTV）推挤，各推 `(重叠量 + margin)/2`（margin=0.015×对角线）；无相交提前收敛；
- 收敛后把各单元自身相对位移经父矩阵逆换算回 `offsetLocal`（L1 编码总位移、L2 编码相对位移，避免父位移重复叠加）。

### 3.4 不变项
- 二级拆分单元选取（`pickExplodeUnits`，上限 40）、爆炸动画、滑杆/按钮交互、相机自适应取景（`frameExploded` 自动适配更大布局）、定位联动（pendingFrame 优先）均不动。
