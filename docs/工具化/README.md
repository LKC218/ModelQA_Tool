# 3D 模型项目审核工具化版本

正式版本由两个独立入口组成，保留原 PoC、原型和实施方案作为验证基线，不覆盖、不删除。

## 开发者编辑端

入口是 `tool/` 下的 Vite 应用，必须通过本地服务器访问。它负责：

- 必须先选中课程才能导入 GLB；未选课程时导入按钮隐藏，选中课程后才显示，并明确显示“导入到：当前课程”。模型支持拖动到其他课程，也可通过“所属课程”备用操作移动。
- 开发者端和审核者端使用顶部横向课程卡片带；点击卡片切换课程，左侧「课程模型」列表展示当前课程模型（固定约 3 行，超出滚动），点列表切换模型；层级树在模型列表下方。
- 多 GLB 导入、项目清单、模型切换、模型元数据编辑和带二次确认的模型删除。删除模型会清理其节点树、当前选择和对应审核记录。
- 项目大标题、课程配置与“课程 → 模型”分组；模型显式绑定 `courseId`，未分配模型进入“未归类”。
- Three.js、GLTFLoader、OrbitControls、Raycaster 和 OutlinePass 的模型查看、层级树、画布/树双向选中、还原视角、线框和局部描边。
- 3D 窗口使用 Poly Haven `brown_photostudio_02` HDR 环境光（离线包内为 384×192 降采样版）；同时使用中性白主光、低强度冷色补光和 ACES 色调映射，降低原暖色灯光造成的偏黄。
- `persistentNodeId` 的 GLB extras 读取、候选路径提示与人工确认绑定。
- 浏览器本地多槽项目（云端长期项目）：编辑后 1.5s 防抖自动保存本地；启动自动恢复当前项目；顶栏可新建/切换/另存为/重命名/复制/删除（上限 50 条，可自定义命名）。项目保存项目元数据与按模型审核记录；GLB 二进制不进本地存储。旧单槽 `an-review-draft` 会自动迁移。
- **云端持久化（P1 已上线）**：项目 JSON 本地优先双写，3s 防抖后同步到服务器（`https://3d.propanda.cn/api/`，Token 鉴权）；导入 GLB 自动上传并按 SHA-256 去重，项目只存 `{hash,url,size}` 引用；启动时与云端对账（本地领先推送、云端有而本地无补拉），换设备打开站点即恢复项目并自动从云端拉回 GLB；顶栏同步圆点（绿=已同步/黄=待同步/灰=离线），列表条目带同步徽标；删除为本地+云端双删，云端失败进待清理队列恢复后重试；断网可继续编辑，恢复后自动补同步（指数退避重试 3 次）。实现见 `tool/src/editor/cloud-sync.js` + `main-implementation.js`；服务端见 `G:\项目\服务器部署\`（`modelqa-data-server.py` + `deploy_data_service.py`）。
- 使用固定审核运行时与当前项目数据重新序列化单 HTML 或 ZIP，绝不读取原 HTML。
- **云端模型库（已上线）**：「导入到 <课程>」按钮提供两路——从本机导入 / 从云端模型库选择。模型库面板列出服务器已存全部 GLB（按文件名搜索），点选即 fetch 载入当前课程并直接记 `{hash,url,size}` 引用（不重复上传）；本机导入的 GLB 自动入库（按内容 SHA-256 去重，文件名记入服务端元数据）。
- **审核包一键导出+上传（P2 已上线）**：导出单 HTML 一步到位——本地下载与云端上传自动并行，toast 先显示「已下载，正在上传在线预览…」，完成后直接给出在线预览链接 + 「复制链接」（`https://3d.propanda.cn/reviews/<名称>-<时间戳>.html`，同名不覆盖），审核员手机/PC 浏览器直接打开即审；上传失败不阻塞（文件已下载成功），toast 提供「重试」；导出区次级按钮「上传在线预览」可对最近一次导出产物补传/重传（localStorage 记最近产物文件名，页面刷新后内容不在内存会提示重新导出）；ZIP 导出不适用在线预览（toast 仅提示）。

运行：双击 `tool/启动开发者编辑端.cmd` 即可启动本地服务器并自动打开浏览器；也可以在 `tool/` 中执行 `npm run dev`。`npm run build` 会先生成审核端固定运行时，再输出开发端生产构建。

**审核端本地预览**：开发服务器运行时打开 `http://localhost:<端口>/reviewer-preview.html`（如 `http://localhost:5173/reviewer-preview.html`），页面内置一份样例审核包（两个示例模型、预置审核结论与模型级/零件级 Issue），可完整体验课程条、层级树、零件点选与描边定位、Issue 卡片和亮/暗主题切换。该页面仅供本地预览，正式审核包仍由开发端导出。

## 审核者端

审核者只打开导出的单 HTML，或先解压 ZIP 后打开其中的 `审核器.html`。ZIP 模式下打开 HTML 后，可将**包含 `project.json` 的解压根目录**拖到中央画布（或点「选择审核包文件夹」）完成一次授权；不要只拖 `models/` 子目录。审核端不依赖开发者服务器、CDN、浏览器缓存或外部资源。

- 单 HTML 只用于模型资源总量不超过 20 MB 的项目，GLB 会分块 Base64 内嵌。
- 资源超过 20 MB 时，开发端禁用单 HTML 并提示使用 ZIP。
- ZIP 固定包含 `审核器.html`、`project.json`、`models/` 和 `review/issues.json`。
- HDR 资源位于 `tool/public/hdri/brown_photostudio_02_2k.hdr`（文件名保留历史 2k，内容为 384×192 降采样 RGBE，约 288 KB；可用 `tool/scripts/build/downsample-hdr.py` 从更高分辨率源重新生成）；资源来源为 [Poly Haven Brown Photo Studio 02](https://polyhaven.com/zh/a/brown_photostudio_02)，遵循其 CC0 许可。构建审核端时会以 Data URL 内嵌到固定运行时，导出的单 HTML/ZIP 不依赖外部 CDN。无模型时导出的单 HTML 约 1.8 MB。
- 审核端支持课程树、模型独立结论、模型级/零件级 Issue、问题定位、节点描边。审核结果三导出：主按钮「导出已审 ZIP」（`审核器.html` + `project.json` + `review/issues.json` + `models/*.glb`，解压后可再拖放打开，避免大项目单 HTML 膨胀）；inline 小包另保留「导出已审 HTML」；次按钮「JSON」仍导出 `{项目}-审核结果.json`，字段与既有 schema 兼容。ZIP/folder 模式隐藏已审 HTML。问题以 `review.byModel[modelId]` 独立保存，零件问题必须带当前模型的 `persistentNodeId`。
- 每次打开（页面重新加载）会自动进入 **9 步**聚光灯功能引导：拖入审核包 → 选课程 → 选模型 → 模型层级 → 双击聚焦零件 → 看视口 → 记问题 → 定结论 → 导出已审 ZIP；每步一句动作 + 可选 tip；第 1 步须先加载包；可「跳过引导」或 ESC；完成/跳过仅关闭本轮，不阻止下次自动弹出；顶栏「?」可重新播放。第 1 步卡片步进旁另有「加载审核包」`?` 热点，点击/hover 展示拖入文件夹 GIF 演示。实现见 `tool/src/reviewer/reviewer-onboarding.js`，计划见 `docs/实施方案/审核端功能引导-实施计划-V1.0.md`。
- Chromium 下优先用 `showDirectoryPicker`（默认「下载」）打开审核包，并把目录 handle 存入 IndexedDB；权限仍在时重开 HTML 可自动恢复上次文件夹；失效时空态显示「上次文件夹」与「打开上次文件夹」。`file://` 下 IDB 可能不可用，此时只记忆文件夹名，选择框仍可手选。实现见 `tool/src/reviewer/reviewer-fs-handle.js`。

## V1.1 数据边界

- `project.courses[]`：课程编号、名称与排序。
- `project.models[].courseId`：模型所属课程。
- `review.byModel[modelId]`：模型结论、模型说明及该模型的 Issue。
- `scope: model` 的 Issue 只绑定模型；`scope: node` 的 Issue 同时绑定模型、版本、节点路径和 `persistentNodeId`。
- 读取旧审核包时，没有课程的模型归入“未归类”，旧全局 Issue 按 `modelId` 迁移到对应模型。

## PC 工作台布局

开发者编辑端和导出的审核者端均以三栏工作台为基线：左侧课程/层级、中央模型预览、右侧属性与审核操作。布局支持 `1920×1080`、`1440×900`、`1280×800` 和 `1024×768` 桌面尺寸；左右侧栏按可用宽度收缩，中间画布保持弹性宽度。

- 顶部操作区可换行，标题和长模型、节点文本不会挤出容器。
- 每个侧栏只保留一个纵向滚动区；模型预览标题和工具栏保留画布安全边距。
- 正文、标签和辅助信息采用分级字号、行高与对比度。

## 审核端手机竖屏（≤900px）

审核端在手机竖屏下改为「3D 全屏 + 底部抽屉」；开发端仍保持桌面三栏。

- 断点 `@media (max-width: 900px)`：工作区单栏，左右侧栏改为底部抽屉（`层级` / `审核` Tab 切换），3D 视口占满主区。
- 顶栏精简为标题 + 进度 + 主按钮「导出」+「更多」；文件夹、主题、帮助、已审 HTML、JSON 收进更多菜单。
- 进度手机显示 `已审/总数`（如 `1/2`），完整统计在 `title`；桌面仍显示 `N通过 · N待改 · N阻断`。
- `height: 100dvh` + `safe-area-inset`；关键触控目标 ≥44px；Issue 删除按钮触控常显。
- 画布点选改为 `pointerup` 判定：位移超过 8px 视为旋转，不触发零件选中。
- 加载策略：优先打开电脑导出的「已审 HTML」；ZIP 文件夹授权保留为次要路径。导出 HTML 壳已带 `viewport-fit=cover`。

### 细分断点（防挤压）

| 断点 | 规则 |
|------|------|
| `≤400px` | 隐藏课程条左右箭头；卡片 `≤168px` |
| `≤900px` 且 `≤700px` 高 | 顶栏/课程条压缩；抽屉 `≤48dvh`；tabs ≥48px |
| `≤900px` 且 `≤500px` 高（横屏） | 卡片单行、隐藏 meta；抽屉 `≤50dvh`；tabs ≥44px |
| `min-width:901px` 且 `≤800px` 高 | 桌面矮窗压缩（不再覆盖手机 tabs） |

冒烟：`tool/scripts/smoke/smoke-mobile.py`（320/360/390/430/横屏/桌面矩阵）。改 `shared-ui.css` 或审核端源码后需 `npm run prepare:reviewer` 再预览离线 runtime。开发端与 onboarding 移动端重排不在本轮。

## 选中态与三维描边

课程选中态控制顶部课程卡与左栏「课程模型」列表；当前模型在列表中独立高亮，与层级树当前节点强调样式分离。

三维节点选中使用 Three.js `OutlinePass` 对目标网格绘制 Blender 风格细描边，不修改材质或贴图颜色。取消选中、切换模型和更换零件时清空描边对象；父节点只将其可渲染子网格加入当前选中集合。

左侧课程/层级栏保留滚动能力，使用窄轨道、圆角滑块和悬停强调；课程组、模型列表和导入后的模型项保留统一上下留白，避免选中边缘裁剪和内容挤压；鼠标滚轮、触控板与键盘滚动继续有效。

## 零件隔离与快捷键

隔离只限制可见性与画布命中范围，不接管「当前选中谁」；`state.selected` 与 `viewer.isolated` 解耦。

- 单击选中零件；再次单击或双击树节点可进入/切换聚焦零件。
- 隔离中：点击隔离子树内的实体零件只换选中，不退出隔离；点击幽灵件或空白也不退出，避免误触。退出只走 ESC、「退出隔离」按钮或再按 G。
- 快捷键 `G`：对当前选中零件切换隔离。焦点在 `input` / `textarea` / `select` / 可编辑区域时忽略；忽略按键连发与修饰键组合。
- 按钮与树节点 title 提示携带 `(G)`；ESC 仍只负责退出，不与 G 的 toggle 抢语义。

## 模型层级树可读性

`renderTree`（`shared-components.js`）默认降低长层级噪音，且不改节点原名。

- **折叠**：仅组节点可折叠；chevron 点击只折叠/展开，不触发选中。默认展开根下第一层，更深层（总成内零件）先收起；折叠组右侧显示叶子数量摘要。
- **前缀弱化**：子节点名与父名存在公共前缀时，前缀用弱化色渲染，差异段保持主色；全文仍在 `title`。无公共前缀则整行普通渲染，不硬切。
- **行内过滤**：树面板搜索框匹配零件名；命中片段高亮，祖先路径自动展开；无结果显示统一空态。
- **自动展开**：选中、过滤时自动展开祖先，保证 active 行可见并滚入视口。
- 展开状态按模型 root 记忆，刷新树后不丢失用户折叠习惯。

## 课程导航与交互动效

- 顶部课程卡片保持单行横向滚动，使用左右滚动按钮和边界反馈；卡片主体负责课程切换，右侧「模型 N」按钮展开模型快速导航。
- 课程卡片采用编号 + 两行标题 + 底部元信息（开发者端为模型数徽章，审核端为 `已审核/总数` 徽章）；空课程显示虚线框与「暂无模型」。
- 选中态使用左侧 3px 琥珀 inset 条 + 底边淡条 + 琥珀浅底；未选中非空卡片 `opacity: 1`，空卡片默认 `opacity: 0.58`。
- 顶栏标题右侧为动态副标题：「选课」步骤字（accent/11px/800/字距）+ 当前课程 `code · name`（或未选课提示）；课程条仅保留卡片滚动带与导入按钮，左右切换按钮 40px，滚动边界自动禁用。「模型层级」标题右侧 `?` 热点 hover/focus 弹出「聚焦零件」GIF 说明；功能引导第 1 步徽标旁 `?` 弹出「加载审核包」GIF 说明（均为 data URL 内嵌，不依赖外部图片文件）。
- 模型导航面板支持搜索、模型切换、开发者端删除及拖放移动；面板为浮层，不推动工作区高度。
- **双端共享 UI 层**：骨架与通用组件样式唯一来源于 `tool/src/shared/shared-ui.css`（Design Token 亮/暗双主题 + 骨架 + 组件）。开发端直接 `import`，审核端由 `build-reviewer.mjs` 经 `globalThis.__AN_SHARED_CSS__` 注入运行时；共享渲染函数位于 `tool/src/shared/shared-components.js`（`renderCourseRail` / `renderTree` / `emptyState`），双端课程条与层级树同源渲染。禁止再整段复制样式或渲染代码后加 `review-` 前缀。

## 双端共享 UI 层（三层模型）

| 层 | 内容 | 策略 |
|---|---|---|
| 骨架层 | 顶栏 + 课程条 + 三栏布局 + 常驻 3D 视口 + HUD/工具条 + 底栏 | 双端完全一致，同源代码 |
| 组件层 | 按钮/面板卡片/课程卡片/层级树/表单/空态/徽章 | 双端完全一致，同源代码 |
| 内容层 | 左栏列表行为、右栏面板内容 | 各端定制，只填内容，不改共享样式 |

允许的端差异清单（清单外差异应下沉到共享层）：

- 开发端独有：课程管理入口（项目设置 Drawer）、拖放移动模型、导入按钮、审核包导出、主题切换。
- 审核端独有：Issue 表单、审核状态色与模型行状态圆点（pending/pass/risk/block）、已审 HTML / JSON 双导出。
- 全局按钮、树节点、课程卡片和问题状态使用短时透明度/位移动效；节点定位保留 3D 描边和短暂聚焦反馈。
- 动效只使用 `opacity`、`transform` 等合成属性，并在 `prefers-reduced-motion: reduce` 时降级为即时状态。
