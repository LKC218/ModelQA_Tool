# 爆炸视图与部件标注功能实施方案

> 版本：V1.0 ｜ 日期：2026-09-12 ｜ 状态：已实施

## 1. 背景与目标

3D 审核视口新增两个通用能力，双端（开发者编辑端 / 离线审核端）同时生效：

1. **爆炸视图**：一键把装配体按部件拆开，滑块控制爆炸程度；
2. **部件标注**：部件锚点自动生成标签 + 引线，帮助定位零件。

## 2. 前置扫描结论（抽样 5 个 GLB，覆盖 34 个模型库）

| 模型 | 结构 | 爆炸 | 标注 |
|---|---|---|---|
| 汽车交流发电机 | 69 节点 / 61 mesh，4 大总成分组 | ✅ | ✅ |
| 三相异步电动机 | 39 节点，深层级 | ✅ | ✅ |
| NPN三极管 / 74LS04 | 扁平多部件（3 电极 / 15 引脚） | ✅ | ✅ |
| 1000μF电容 | 单 mesh | ❌ 自动禁用 | ✅ 标整体 |

关键前提：**GLB 节点 100% 命名**，命名即业务语义，标注文字可直接取自部件名。

## 3. 技术设计

### 3.1 爆炸功能（shared-viewer.js 新增 explode API）

- **爆炸单元**：取模型根节点的一层子节点；若根下只有 1 个分组则下钻一层（对应发电机「01_转动总成…」粒度）。
- **偏移向量**：每个单元沿「自身世界中心 → 模型整体中心」反向偏移，距离 = `dist(单元中心, 模型中心) + 模型对角线 × 0.18`，保证中心部件也能弹出。
- **坐标系换算**：世界偏移向量经父节点世界矩阵求逆换算为本地偏移，兼容任意层级旋转/缩放。
- **动画**：滑块拖动即时响应；按钮点击 0↔1 用指数趋近平滑过渡（animate 循环内插值）。
- **自动复位**：animate 循环检测 `getRoot()` 变化（切模型），自动还原旧部件位置、爆炸系数归零，并通过 `onViewStateChanged` 回调同步 UI。
- **可炸性判定**：单元数 < 2 时按钮禁用（单 mesh 模型）。

### 3.2 部件标注（CSS2DRenderer + 引线）

- 叠加层：`CSS2DRenderer` 覆盖在 canvas 上方，`pointer-events: none` 不干扰拾取/旋转。
- 标签单元与爆炸单元一致（可炸模型标总成，单部件模型标整体），上限 24 个防杂乱。
- 锚点：单元世界包围盒顶面中心；引线：`THREE.Line` 从锚点垂直向上到标签点。
- 联动：爆炸系数变化时实时重算锚点与引线；引线颜色跟随主题 `outline` 色令牌。
- 标签样式：面板芯片样式（CSS 变量适配亮/暗主题）。

### 3.3 UI 接入（两端 toolbar）

`.viewer-toolbar` 在「线框」后新增：

- `#explode` 爆炸按钮：点击 0↔1 平滑切换，激活时展开 `.viewer-explode` 滑块行（0–100%）；
- `#labels` 标注按钮：开关部件标注；
- 单部件模型爆炸按钮自动 `disabled`。

## 5. 测试方案

1. **构建验证**：`npm run build` 通过（含 prepare:reviewer）。
2. **视口功能验证**：dev 服务 + 浏览器实测——加载发电机 GLB，验证：
   - 爆炸按钮平滑拆开 4 大总成，滑块 0–100% 连续可控；
   - 标注芯片 + 引线显示、跟随爆炸、切模型自动清空；
   - 拾取/选中描边/聚焦零件/线框不回归；
   - 截图人工复核。
3. **边界**：单 mesh 模型（电容）爆炸按钮禁用；切模型自动复位爆炸与标注按钮态。

## 6. 部署方案

- `vite build` 产出 `tool/dist`（单 HTML + hdri/help 静态资源）；
- 通过 WorkBuddy「发布为应用」以静态站点发布 dist，输出在线预览链接。

## 7. 风险与对策

| 风险 | 对策 |
|---|---|
| 模型无层级（单 mesh） | 可炸性检测，按钮禁用 |
| 引线过多杂乱 | 标注单元与爆炸单元对齐 + 24 上限 |
| 切模型残留爆炸位移 | 根节点自动检测 + 位置还原 |
| 亮/暗主题可读性 | 全部走 CSS 变量与 outline 色令牌 |
