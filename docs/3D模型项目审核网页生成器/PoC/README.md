# 3D 模型审核网页生成器 PoC

本目录是阶段 1 的可双击离线验证版本。打开 `模型审核-PoC-生成器.html`，导入单个 `.glb` 后可读取节点层级、选择节点高亮、填写一条 Issue，并导出完整结果 HTML。

导出结果使用固定运行时模板和当前数据重新序列化，不读取原 HTML，也不依赖 CDN、服务器或浏览器缓存。单 HTML 的建议阈值为内嵌后不超过 20 MB；超过阈值时页面只给出 ZIP 审核包提示，ZIP 路线要求审核人主动选择解压后的文件夹。

PoC 只验证单 GLB 与最小 Issue 闭环，不代表 MVP 已完成，也不承诺任意 GLB 的材质、动画或复杂变换兼容性。

正式工具化版本位于仓库根目录 `tool/`，使用 Three.js + GLTFLoader + OrbitControls；PoC 页面保留作为原始验证基线，不覆盖、不删除。
