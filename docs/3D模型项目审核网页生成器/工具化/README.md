# 3D 模型项目审核工具化版本

正式版本由两个独立入口组成，保留原 PoC、原型和实施方案作为验证基线，不覆盖、不删除。

## 开发者编辑端

入口是 `tool/` 下的 Vite 应用，必须通过本地服务器访问。它负责：

- 必须先选中课程才能导入 GLB；导入区明确显示“导入到：当前课程”。模型支持拖动到其他课程，也可通过“所属课程”备用操作移动。
- 多 GLB 导入、项目清单、模型切换、模型元数据编辑和带二次确认的模型删除。删除模型会清理其节点树、当前选择和对应审核记录。
- 项目大标题、课程配置与“课程 → 模型”分组；模型显式绑定 `courseId`，未分配模型进入“未归类”。
- Three.js、GLTFLoader、OrbitControls、Raycaster 和 OutlinePass 的模型查看、层级树、画布/树双向选中、适配、线框和局部描边。
- `persistentNodeId` 的 GLB extras 读取、候选路径提示与人工确认绑定。
- 浏览器本地草稿保存/恢复。草稿保存项目元数据与按模型审核记录，浏览器安全边界下恢复后须重新选择 GLB 文件。
- 使用固定审核运行时与当前项目数据重新序列化单 HTML 或 ZIP，绝不读取原 HTML。

运行：双击 `tool/启动开发者编辑端.cmd` 即可启动本地服务器并自动打开浏览器；也可以在 `tool/` 中执行 `npm run dev`。`npm run build` 会先生成审核端固定运行时，再输出开发端生产构建。

## 审核者端

审核者只打开导出的单 HTML，或先解压 ZIP 后打开其中的 `审核器.html` 并选择审核包文件夹。审核端不依赖开发者服务器、CDN、浏览器缓存或外部资源。

- 单 HTML 只用于模型资源总量不超过 20 MB 的项目，GLB 会分块 Base64 内嵌。
- 资源超过 20 MB 时，开发端禁用单 HTML 并提示使用 ZIP。
- ZIP 固定包含 `审核器.html`、`project.json`、`models/` 和 `review/issues.json`。
- 审核端支持课程树、模型独立结论、模型级/零件级 Issue、问题定位、节点描边与 JSON 审核结果导出。问题以 `review.byModel[modelId]` 独立保存，零件问题必须带当前模型的 `persistentNodeId`。

## V1.1 数据边界

- `project.courses[]`：课程编号、名称与排序。
- `project.models[].courseId`：模型所属课程。
- `review.byModel[modelId]`：模型结论、模型说明及该模型的 Issue。
- `scope: model` 的 Issue 只绑定模型；`scope: node` 的 Issue 同时绑定模型、版本、节点路径和 `persistentNodeId`。
- 读取旧审核包时，没有课程的模型归入“未归类”，旧全局 Issue 按 `modelId` 迁移到对应模型。

## PC 工作台布局

开发者编辑端和导出的审核者端均以三栏工作台为基线：左侧课程/层级、中央模型预览、右侧属性与审核操作。布局支持 `1920×1080`、`1440×900`、`1280×800` 和 `1024×768` 桌面尺寸；左右侧栏按可用宽度收缩，中间画布保持弹性宽度。

- 顶部操作区可换行，标题和长模型、节点文本不会挤出容器。
- 每个侧栏只保留一个纵向滚动区；模型预览标题和工具栏保留画布安全边距。
- 正文、标签和辅助信息采用分级字号、行高与对比度；不在本轮承诺移动端重构。

## 选中态与三维描边

课程展开状态与课程选中状态分离：展开只控制课程模型列表的显示，当前模型所属课程才显示课程选中态；当前模型和当前节点分别使用独立的层级强调样式。

三维节点选中使用 Three.js `OutlinePass` 对目标网格绘制 Blender 风格细描边，不修改材质或贴图颜色。取消选中、切换模型和更换零件时清空描边对象；父节点只将其可渲染子网格加入当前选中集合。

左侧课程/层级栏保留滚动能力，使用窄轨道、圆角滑块和悬停强调；鼠标滚轮、触控板与键盘滚动继续有效。

拖放代码已实现课程目标高亮和松开后更新 `courseId`，但内置 Chromium 的坐标拖动自动化未产生可确认的状态变化；需在目标 Chrome/Edge 手工补测原生拖放。删除模型的二次确认和实际删除也需在目标浏览器执行确认弹窗后补测。

2026-09-07 已在本地 Vite 服务的内置 Chromium 中导入 `1N4007续流二极管.glb` 和 `2AP9二极管.glb`，确认项目大标题、`AN-01`/`AN-02` 课程分组、模型切换、首模型 5 节点层级、节点候选 ID 人工确认和单 HTML 生成路径。构建、源码语法检查和更新后的开发端运行错误检查均通过。

- ZIP 解压目录加载、超过 20 MB 的真实 GLB、10/30/50 MB 内存与性能、复杂 GLB 材质/动画/蒙皮仍需在目标审核电脑验证。
