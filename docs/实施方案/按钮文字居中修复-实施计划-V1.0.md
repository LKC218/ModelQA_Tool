# 按钮文字居中修复 实施计划 V1.0

> 本文档自包含，新会话可直接按此执行。  
> 背景先读：`docs/apps-code-map.md`、`tool/src/shared/shared-ui.css`。  
> 已拍板：在**共享层**统一修按钮垂直/水平居中，不单点修「更多」。

## 1. 背景与问题

| 现象 | 说明 |
|---|---|
| 移动端顶栏「更多」 | 比「导出」更高，中文文字偏上/不居中 |
| 绿色「导出」 | 内部为 `span.only-sm` / `span.hide-sm`，与纯文本按钮表现不一致 |
| 根因 A | `.button` / `.icon-button` 只有 `min-height`，无 flex 垂直居中 |
| 根因 B | `.topbar .actions` 为 flex，默认 `align-items: stretch`，行内最高控件撑高邻钮 |
| 根因 C | `.only-sm { display: inline-flex !important }` 加在 **按钮** 上会覆盖按钮自身 display 且未设 `align-items` |

```281:293:tool/src/shared/shared-ui.css
.button,
.icon-button,
.text-button {
  min-height: 36px;
  padding: 0 13px;
  ...
  line-height: 1;
  /* 缺 display / align-items / justify-content */
}
```

```968:974:tool/src/shared/shared-ui.css
.only-sm { display: none !important; }
/* ≤900px */
.only-sm { display: inline-flex !important; }
.hide-sm { display: none !important; }
```

## 2. 目标与非目标

**目标**

1. 全站 `.button` / `.icon-button` 文字在任意 `min-height`（36/44/48）下**几何居中**。
2. 顶栏 `.actions` 内按钮**同高对齐**，「更多」与「导出」视觉一致。
3. 图标+文案、纯文案、多 `span` 切换文案均居中。
4. 不改业务逻辑、按钮 id、导出/审核行为。

**非目标**

- 不重做移动端 IA / 抽屉 / 更多菜单结构。
- 不改 `.text-button` 为块级按钮样式（保持行内文本链路）。
- 不引入新 UI 库或组件封装。
- 不为居中单独加 JS。

## 3. 设计原则

1. **共享契约优先**：居中写在 `shared-ui.css` 的按钮基样式，开发端/审核端同时受益。
2. **显隐与布局分离**：`only-sm` / `hide-sm` 只负责 show/hide，不强制按钮 display。
3. **KISS**：CSS-only，不改 DOM 结构（除非 class 误用需最小调整）。
4. **触控目标不降**：`min-height` 维持 36（桌面）/ 44（≤900px）。

## 4. 技术方案

### 4.1 按钮基样式（主修）

在 `tool/src/shared/shared-ui.css` 将 `.button` 与 `.icon-button` 改为 flex 居中（与 `.text-button` 拆开）：

```css
.button,
.icon-button {
  display: inline-flex;
  align-items: center;
  justify-content: center;
  gap: 6px;
  min-height: 36px;
  padding: 0 13px;
  border: 1px solid var(--line);
  border-radius: var(--radius-sm);
  background: var(--card);
  color: var(--text);
  font-size: 13px;
  font-weight: 700;
  line-height: 1;
  text-align: center;
}

/* .text-button 保持原样：min-height:auto; 不使用 inline-flex 按钮壳 */
```

可选（防「导出已审 ZIP」在窄宽换行导致邻钮被撑高）：

```css
.topbar .actions .button {
  white-space: nowrap;
}
```

### 4.2 顶栏 actions 对齐

```css
.topbar .actions {
  align-items: center;
}
```

避免 stretch 把矮按钮拉高。

### 4.3 only-sm / hide-sm 只做显隐

现状问题：按钮挂 `only-sm` 时被 `inline-flex !important` 接管，且无居中。

修改原则：

| 目标元素 | 显隐 |
|---|---|
| 按钮 `#mobile-more.button.only-sm` | 桌面 `display: none !important`；≤900px **恢复按钮自身** `inline-flex`（不要用 `inline-flex` 覆盖成“无对齐的 flex”） |
| 按钮内 `span.only-sm` / `span.hide-sm` | 桌面/移动互斥显示，用 `inline` 或 `inline-flex` 均可，**不带**强制改按钮 |

推荐写法（示意）：

```css
.only-sm { display: none !important; }
.hide-sm { display: contents; /* 或保持默认 */ }

@media (max-width: 900px) {
  .only-sm { display: initial; } /* 不强制 inline-flex */
  button.only-sm,
  .button.only-sm { display: inline-flex !important; align-items: center; justify-content: center; }
  .hide-sm { display: none !important; }
}
```

更稳妥：评估是否改为「按钮始终 `inline-flex`，显隐用独立 class `.is-mobile-only / .is-desktop-only`」，避免 `only-sm` 与按钮 display 抢优先级。P0 优先**最小 diff**：补居中 + 收紧 `only-sm` 对 `button` 的覆盖。

### 4.4 审核端/开发端影响面

| 位置 | 预期 |
|---|---|
| 开发端顶栏（导出审核包等） | 一律居中，无行为变化 |
| 审核端桌面顶栏（已审 ZIP/HTML/JSON） | 居中 |
| 审核端移动顶栏「更多」「导出」 | 同高、文字居中 |
| Viewer `.icon-button`、分段控件 | 不受 `.button` 影响（分段有独立样式） |
| `.mobile-tabs button` | 另有规则；本计划不强制改，若验收发现偏上再补 `align-items: center` |

### 4.5 不改文件

- 业务 JS 逻辑：`main-implementation.js` / `reviewer-implementation.js`（除非仅改 `only-sm`/`hide-sm` class 挂在按钮上的用法——P0 建议 **不改 JS**）
- 构建脚本、导出链路

## 6. 边界与风险

| 风险 | 处理 |
|---|---|
| 原依赖 `inline-block` 的间距/基线变化 | 验收顶栏、工具条、Drawer 内按钮；`gap: 6px` 兜底图标文案 |
| `display: contents` 兼容 | 若 hide-sm 用 contents，Chromium/现代浏览器 OK；回退可不写 contents |
| `only-sm` 优先级仍压过按钮 | 用 `button.only-sm` 提高特异性或调整 only-sm 规则 |
| 分段按钮 / 菜单项非 `.button` | 本计划不强制；单独验收再补 |
| 开发端无移动端「更多」 | 仍应通过桌面按钮居中冒烟 |

## 7. 阶段划分

### P0（本计划必做）

1. `shared-ui.css`：`.button` / `.icon-button` → inline-flex 三件套居中。
2. `.topbar .actions { align-items: center }`。
3. 收敛 `only-sm` 对按钮的 display 覆盖，保证「更多」与「导出」同视觉高度与居中。
4. `npm run build` 通过。
5. 桌面 + ≤900px 视口截图/目视验收。

### P1（本计划不实现）

- 统一移动端 class 体系（`is-mobile-only` 替代 only-sm 挂按钮）。
- `.mobile-tabs`、`.rail-scroll` 等全量触控按钮居中审计。
- 设计 Token 化按钮高度。

## 8. 验收清单

- [ ] 桌面审核端：顶栏「导出已审 ZIP / 已审 HTML / JSON / 主题 / 帮助」文字垂直居中、高度一致。
- [ ] ≤900px 审核端：「导出」与「更多」等高，「更多」文字不贴顶。
- [ ] 开发端桌面顶栏按钮居中，无回归。
