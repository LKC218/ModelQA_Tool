# 云端模型库缩略图网格与文件夹树分类 实施计划 V1.0

> 本文档自包含，新会话可直接按此执行。
> 背景先读：`docs/apps-code-map.md`、`docs/实施方案/开发端云端持久化与审核包在线托管-实施计划-V1.0.md`（云端接口契约与部署惯例）。
> 讨论结论（已与开发者确认）：借鉴 D5 资产库「看图选模型」的信息架构，但只借视觉语言与轻量筛选，**不搬** Online/Local 双页签、收藏、手动打标分类。分类来源改为**真实文件夹路径**——本地 `Model/` 目录按「实训室/课题」两级组织（如 `AN-模拟电路实训室/AN-01 二极管认知与检测/xxx.glb`），路径随上传入库，树由前端推导，零打标维护。
> 已拍板：`paths` 存**数组**（同内容 GLB 可挂多节点）；缩略图**前端离屏渲染 + IndexedDB 按 hash 缓存**；树在**前端由 path 前缀 groupBy 推导**，不加新接口。

## 1. 背景与问题

| 现状 | 位置 | 问题 |
|---|---|---|
| 库面板 = 搜索框 + 纯文本列表 | `tool/src/editor/main-implementation.js` `buildLibraryPanel` / `renderLibraryList` | 文件名 + 体积无法识别模型，须逐个载入试错 |
| 路径信息上传时丢失 | 服务端 `modelqa-data-server.py` `post_model`：每 hash 只存 `{fileName, size, uploadedAt}` | 云端库无「实训室/课题」归属结构 |
| 库持续累积 | `models/<hash>.glb` 按 hash 去重 | 无分类、无状态筛选，找模型效率随量下降 |

## 2. 目标与非目标

**目标**

1. **P0** 库面板文本列表 → 缩略图网格卡片，支持密度切换（大图/中图/列表）；缩略图前端离屏渲染，按 hash 缓存，二次打开零成本。
2. **P1** 编辑端导入菜单新增「按文件夹导入」：`webkitdirectory` 遍历子目录，`webkitRelativePath` 归一化后随上传携带（请求头 `X-ModelQA-Path`）。
3. **P1** 服务端 `models/<hash>.json` 增加 `paths: []` 数组字段；**dedup 命中也合并写回 paths**（存量模型靠重导一次补录，无需迁移脚本）。
4. **P1** 库面板左侧渲染**单级大分类**（用户已拍板：以原始文件夹第一层为准，如 `AN-模拟电路实训室 / DG-数字电路实训 / MT-电机控制实训`，含计数与「未分类」兜底；完整路径仍存 `paths` 数组留档，细化到课题级仅为将来前端展示改动）与平铺状态筛选（全部/最近导入/本项目已用/未使用）；树管「归属」、平铺筛管「状态」、搜索管「关键词」，三者叠加 AND。

**非目标**

- 不做手动分类打标 UI、收藏、付费、Online/Local 双页签。
- 不做云端树与本地文件夹实时镜像：树是**导入时刻的快照**，本地移动/重命名后需重导一次（dedup 只刷元数据，成本低）。
- 不改审核端离线运行时与导出契约（schemaVersion 不变）。
- 服务端不据 path 落目录，path 仅作展示与过滤元数据。
- 不做跨项目「已用」统计（P1 口径 = 当前项目已用/未用，跨项目统计后置）。

## 3. 关键决策

| # | 决策 | 选择 | 理由 |
|---|---|---|---|
| 1 | path 语义 | `paths` 数组（合并去重，上限 20） | 同一 GLB 出现在多个课题目录时可在多节点下呈现；单值「首见优先」语义失真 |
| 2 | 缩略图缓存 | IndexedDB（库 `modelqa-thumbs`），key = hash | localStorage 有 5MB 配额风险；项目已有 IndexedDB 先例（`reviewer-fs-handle.js` 的 `an-reviewer-fs`） |
| 3 | 生成时机 | 打开面板后按视口懒生成（IntersectionObserver），并发 2 | 34+ 模型同步全量生成会卡顿；大 GLB 首帧解析耗时不可控 |
| 4 | 渲染失败 | 降级为占位立方体图标，不阻塞列表 | 网络/解析/WebGL 任一失败都只损失该卡片缩略图 |
| 5 | 树数据 | 前端 groupBy，无新接口 | `GET /api/models/list` 返回的 `paths` 已足够推导两级树 |
| 6 | 主题 | 沿用现有亮/暗双主题 CSS 变量 | 不引入 D5 深色为默认；编辑端已有 `modelqa-theme` 体系 |

## 4. 数据链路

```text
本地 Model/ 文件夹树（AN-模拟电路实训室/AN-01 课题/xxx.glb）
  │  「按文件夹导入」webkitdirectory → webkitRelativePath（\ 归一化为 /）
  ▼
编辑端 addFiles(files, {relPath}) → uploadModelToCloud(model, relPath)
  │  POST /api/models，header: X-Model-Filename + X-ModelQA-Path（encodeURIComponent）
  ▼
服务端 post_model：hash 去重落盘（不变）；读 X-ModelQA-Path
  │  sanitize_path（逐段清洗、段数≤6、去空）→ 合并进 models/<hash>.json 的 paths（去重、上限 20）
  ▼
GET /api/models/list → {models:[{hash, fileName, size, url, paths}]}
  ▼
库面板：paths groupBy → 文件夹树 + 计数；选中节点前缀过滤网格；
  缩略图按 hash 查 IndexedDB → 未命中懒生成（离屏 WebGL 渲染 → dataURL 入库）
```

## 5. 服务端改动（P1）

文件：`G:\项目\服务器部署\modelqa-data-server.py`（部署与备份沿用 `deploy_data_service_update.py` 惯例：服务器侧留时间戳备份）。

### 5.1 `post_model`：接收并合并 paths

- 新增请求头 `X-ModelQA-Path`（URL 编码的相对路径，如 `Model/AN-%E6%A8%A1%E2%80%A6/xxx.glb`）。
- `sanitize_path(raw)`：`unquote` → 反斜杠统一为 `/` → 按段拆分 → 每段过既有 `sanitize_filename` → 丢弃空段与 `.`/`..` → 段数截断至 6、总长截断至 512 字符。**仅作元数据，不参与落盘路径，无穿越风险**。
- 现有逻辑「meta 已存在则跳过写回」改为：读取 meta（不存在则新建，fileName 首见保留规则不变）→ 若本次带 path 且不在 `paths` 中则 append（截断至 20，超出淘汰最早）→ 有变化才原子写回。**dedup 命中也会因 paths 合并而写回**——这是存量补录的关键。

### 5.2 `list_models`：响应附带 paths

- `items.append({... , "paths": meta.get("paths") or []})`。旧 meta 无 `paths` 时返回空数组，前端归入「未分类」。

### 5.3 冒烟

- `_archive/local_smoke_data_server.py` 体系补用例：带/不带 path 头各上传一次同一二进制（第二次 dedup=true 且 paths 刷新）、非法路径段清洗、多目录同 hash 的 paths 合并。

## 6. 前端改动（编辑端 `tool/src/editor/`）

### 6.1 P0：缩略图模块（新文件 `model-thumbnails.js`）

- `getThumb(item)` → `Promise<dataURL|null>`：
  1. IndexedDB（`modelqa-thumbs`，约 40 行 kv 包装）按 `item.hash` 查缓存，命中直接返回；
  2. 未命中入队（并发 2，FIFO）：`cloud.fetchModel(item.url)` → `GLTFLoader.parseAsync` → 离屏渲染；
  3. 离屏渲染：模块级常驻一个 `WebGLRenderer`（256×256，`alpha:true`），场景含半球光 + 平行光（复用 `themeTokens` 的中性光比即可，不必随主题联动），`Box3.setFromObject(scene)` 自适应包围盒摆相机（斜 45° 俯视 + `fit` 距离 = 对角线 × 1.4），渲染一帧 `toDataURL('image/jpeg', 0.85)` 入库；
  4. 任一步失败返回 `null` 并从队列移除（不重试，避免大模型反复拖垮）。
- 缓存容量：上限 500 条，超限按 `savedAt` 淘汰最旧（简单时间戳字段即可，不做真 LRU）。
- IndexedDB 不可用（隐私模式/file:// 异常）→ 降级为模块内存 Map，仅会话内有效。

### 6.2 P0：库面板网格 UI

- `buildLibraryPanel` 头部加密度切换（三个小按钮：大图/中图/列表，写 localStorage `modelqa-lib-density`）；面板根元素按密度挂 `data-density`。
- `renderLibraryList` → `renderLibraryGrid`：`.library-grid` CSS grid `auto-fill minmax(var(--lib-card-min), 1fr)`（大 150px / 中 110px / 列表切换为单列行式，复用现 `.library-item` 行样式）；卡片 = 缩略图区（占位图标先行）+ 文件名（单行省略）+ 体积；点击行为不变（`importFromLibrary`）。
- 缩略图懒生成：卡片插入后 `IntersectionObserver` 可见时调 `getThumb`，回填 `<img>` 或背景。
- `styles.css` 相应增量：`.library-grid`、`.library-card`、`.library-thumb`、密度变量、占位态。

### 6.3 P1：按文件夹导入

- `openImportMenu` 菜单加第三项「按文件夹导入（含子目录）」；动态创建 `<input type="file" webkitdirectory multiple>`（能力检测缺失则禁用该项并 title 说明）。
- `addFiles(files, opts)` 增加可选 `opts`：从 `file.webkitRelativePath` 取相对路径，归一化后存到 model 上；`uploadModelToCloud(model, attempt)` 上传时携带（重试路径同样携带）。
- `cloud-sync.js` `uploadModel(arrayBuffer, fileName, relPath)`：有 `relPath` 时追加 `X-ModelQA-Path: encodeURIComponent(relPath)`。
- 常规「从本机导入」单文件不携带 path（无路径语义），保持不变。

### 6.4 P1：树 + 平铺筛选

- `buildLibraryPanel` 改两栏：左侧 `.library-side`（搜索框上移至此 + 文件夹树 + 平铺筛选），右侧网格。
- 树构建（已拍板：单级大分类）：`libraryCache` 各条 `paths[]` 取**第一段**（剥去根目录名 `Model/`）groupBy → 大分类节点（实训室级）+ 计数；无 paths 的归「未分类」。点击节点 = 该分类过滤（模型任一 path 首段命中即入选）；再点取消。不做课题子级，完整路径留档备将来细化。
- 平铺筛选（单选）：全部 / 最近导入（`uploadedAt` 近 7 天，无则取最新 20 条兜底）/ 本项目已用（当前项目 `state.modelCloudRefs` 的 hash 集合，卡片加「已用」角标）/ 未使用（补集）。
- 搜索保留，与树、筛选三者 AND 叠加；空态文案区分「无匹配」与「未分类兜底」。

## 9. 风险与回退

| 风险 | 缓解 |
|---|---|
| 大 GLB 解析/首帧耗时长 | 懒生成 + 并发 2 + 占位先行；失败不重试 |
| WebGL 上下文占用 | 全库共享一个 256px 离屏 renderer，常驻复用 |
| IndexedDB 不可用 | 降级内存缓存（仅会话内），功能不中断 |
| 老客户端 / 未升级服务端混跑 | `paths` 缺省为空数组 → 全入「未分类」，双向兼容 |
| 服务端异常 | 按 §5 部署惯例时间戳备份回滚；老前端不传 path 头不受影响 |
| 本地目录调整后树过期 | 文档明示「快照语义」：重导一次即刷新，UI 树顶部加「按文件夹导入可刷新分组」提示 |

## 变更记录

### V1.1 分类规则重构：素材路径 → 项目使用（2026-09-11 已实施）

用户拍板：大分类改为**项目制**——模型在哪个项目里使用，就归入该项目名的大类（如「电机控制实训」）；未被任何项目使用的归「未使用」节点。文件夹路径分类不再作主分类，`paths` 仍留档备查。

- **服务端**：`PUT /api/projects/<id>` 先读旧项目 JSON 取旧引用集，落盘后对模型元数据 `projects: [{id, name}]` 做差集增删（改名自动跟随、移除模型自动清引用、上限 20）；`DELETE` 读回项目 JSON 清理引用；`/api/models/list` 返回 `projects` 字段。哈希白名单校验（64 位十六进制）。部署脚本 `服务器部署/deploy_model_projects_update.py`。
- **前端**：`libraryCategories()` 数据源从 paths 首段改为 `projects[].name`，`__uncat__` 改 `__unused__`（显示「未使用」），过滤逻辑同步；面板提示文案更新为「分类按项目使用自动归组」。
- **存量回填**：`服务器部署/backfill_model_projects.py` 重放所有云端项目 PUT（幂等），回填时 2 个项目 → 9/31 模型获得分类（桥式整流模块同属两项目，验证多归属语义）。
- **冒烟**：`local_smoke_data_server.py` 新增项目引用用例（引用/改名/移除模型/删项目清理，31 checks 0 failed）；顺带修复 413 超限用例的竞态（服务端不读体断连时客户端可能收到连接中止，两者均视为拒绝成功）。
