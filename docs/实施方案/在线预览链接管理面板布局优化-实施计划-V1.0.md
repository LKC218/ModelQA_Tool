# 在线预览链接管理面板布局优化 实施计划 V1.0

> 参照归档聊天 UI 重构布局：层级清晰、操作收敛、可搜索。仅改前端，不碰服务端。

## 改动范围

| 文件 | 改动 |
|------|------|
| `tool/src/editor/main-implementation.js` | `buildReviewLinksPanel` / `renderReviewLinks` DOM 与过滤逻辑 |
| `tool/src/editor/styles.css` | 新增 `reviewlinks-` 前缀样式 |

**不动**：服务端接口、`cloud-sync.js`、`.library-panel` / `.library-head` 共享样式（素材库共用，宽度维持 `min(860px, 96vw)`）。

## 任务拆解

### T1 头部一行化
- 左：标题「在线预览链接」+ 计数徽标（当前页签条目数）。
- 右：刷新（图标按钮，保留 `#reviewlinks-refresh`）、关闭 `×`（保留 `#reviewlinks-close`）。
- 刷新从页签排移入头部。

### T2 页签下划线式
- 未审核/已审核改 Tab 样式：无边框按钮，选中项底部 2px 色条 + 主题色文字。
- 保留 `#tab-pending` / `#tab-reviewed` id 与 `.active` 切换逻辑。

### T3 搜索框（前端过滤）
- 页签下方新增输入框 `#reviewlinks-search`，placeholder「按课程名搜索…」。
- 按 `name.includes(keyword)` 过滤当前页签条目，纯前端；清空即全量，切页签保留搜索词。

### T4 行内操作收敛
- 「打开」保留文字主按钮；「复制」→ 图标 ⧉（`title="复制链接"`）；「删除」→ 图标（`title="删除"`，hover 红）。
- `data-op` 属性、行内二次确认逻辑（confirming 红底白字「确认删除」+3s 超时）**完全不变**。

### T5 空态优化
- 空态改为：居中图形 + 主文案 + 次文案（未审页签次文案：「导出单 HTML 后自动上传」）。

### T6 验证与上线
1. E2E：重跑 `tool/scripts/smoke/smoke-review-links.py` → PASS
2. 回归：`smoke-drafts` → PASS
3. `npm run build` + `upload_dist.py` 上线
4. 线上抽查：搜索框 id、下划线页签、图标按钮可见

## 验收标准

- [ ] 头部一行：标题+计数居左，刷新+×居右
- [ ] 页签下划线式，两页签数据与切换正确
- [ ] 搜索过滤当前页签，清空恢复全量
- [ ] 打开/复制/删除（含二次确认）功能不回退
- [ ] E2E + 回归全 PASS，线上正常

## 风险与约束

- E2E 依赖 id：`#reviewlinks-mask / -list / -close / -refresh`、`#tab-pending / #tab-reviewed`、行内 `[data-op]`、行文本 `has_text` —— 重构时全部保留，脚本零改动。
- 删除按钮图标化后，确认态（红底白字）视觉必须足够醒目，防误触。
- 不新增依赖，样式复用现有 token（`--panel/--line/--accent/--danger`）。
