## 5. 实施期发现与修正

1. **dist/reviewer-preview.html 不是自包含产物**（引用 `/src/generated/reviewer-runtime.js`）：file:// 打开 404 空页。探针统一 route 拦截 fulfill 本地 runtime（对齐 probe-e2e-dedup 配方）。
2. **onboarding 引导浮层拦截点击**：探针必须在断言前 `#onb-root.remove()`。
3. **grid-column `1 / -1` 的 computed 值是字面 `"-1"`**（不解析为线号 3）：S1c 断言曾因此误判 FAIL。
4. **≤400 块 toolbar bottom 覆盖**：peek 常驻后 ≤400 的 `bottom:8px` 会盖住 toolbar（390 宽视口命中），删除该行继承 ≤600 的 54px。
5. **venv 无 paramiko**：upload_dist.py 需用托管 3.13.12 或系统 3.12 直跑。
6. **`.is-app` 架构收益**：原计划 61 处规则双端各写一套，引入共同形态根类后 ≤600 形态规则零复制，编辑端 P3 仅 +1 个 IIFE 和 1 行 DOM。
