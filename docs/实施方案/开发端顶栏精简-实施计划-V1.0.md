### V1.2 审核端顶栏操作重构（2026-09-11 已实施，P0+P1+P2 全量）

用户需求：审核端右上角按钮群不人性化。实施原则：**任何时刻只突出一个正确的出口；入口归入口、出口归出口**。

- **P0 流程分组与改名**：按 `进度 → 入口 → 出口 → 工具` 重排并加分隔线（`.topbar-sep`）；「JSON」改名「导出 JSON」并移入下拉；🌙 主题切换并入 ⚙ 设置抽屉（settings.js 新增可选 `opts.theme = {get,set}`，「主题：亮色/暗色」段；不传 opts 的旧调用行为不变），移动端「更多」菜单保留切换主题项（直调 applyReviewerTheme）。
- **P1 出口收敛**：「选择审核包文件夹」改为「打开审核包 ▾」下拉（选择文件夹 / 打开上次文件夹，复用 reviewer-fs-handle 记忆，无记忆时隐藏「打开上次」）；「导出 ▾」下拉收纳 导出已审 HTML + 导出 JSON；主按钮包类型自适应——ZIP 包亮「导出已审 ZIP」、单 HTML 包亮「导出已审 HTML」（回传可用时回传优先为主按钮）、在线包亮「回传审核结果」；`syncExportButtons` 增加 primary class 同步。
- **P2 完成引导**：全部模型审完时主出口按钮呼吸高亮（`.button.attn` ring 动画）+ 一次性状态提示「✓ 审核已全部完成，可回传或导出已审结果」；点击任一出口即停止高亮；重新加载包时状态复位。
- **冒烟同步**：`smoke-export-reviewed.mjs` 改为先展开「导出 ▾」再点菜单内按钮。回归：smoke-export-reviewed（node 运行）+ smoke-model-library + smoke-export-upload + smoke-drafts 四组全 PASS。
